## Production rules

- Use real screen recordings and approved screenshots from each repository.
- Do not invent predictions, metrics, payment confirmations, users or feature states.
- Use dummy data for private repositories and hide credentials and personal information.
- Label research prototypes and missing inference capabilities honestly.
- Export final files as MP4 (H.264), 1920×1080, 24 or 30 fps.

## Output repository

Final MP4 files will be organized by repository name after the destination video repository is selected. No generated MP4 is included in this repository yet.
